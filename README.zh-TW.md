# Marquee Row

<p align="center">
<a href="README.md">English</a> | <a href="README.ja.md">日本語</a>
</p>

一款把 Stream Deck 上的一整排(或一整欄)鍵組合成一個跑馬燈顯示區的外掛。把動作放到同一排的每一顆鍵上,這些鍵就會拼成一條連續的捲動文字,就像早期的跑馬燈跑字幕一樣。

## 功能特色

- **跨鍵渲染**:一份文字無縫橫跨你指定的所有鍵捲動顯示,每顆鍵會依照自己實際所在的欄/列位置自動判斷該顯示哪一段。
- **群組同步**:同一個 Group ID 底下的鍵,文字、速度、顏色、方向都共用。編輯其中任何一顆鍵,其他鍵會自動同步——文字只需要打一次。
- **四種捲動方向**:由右往左、由左往右(橫排),以及由上往下、由下往上(直排,文字逐字堆疊,適合日文/韓文排版)。
- **即時變數**:`{{date}}`、`{{time}}`、`{{HH:MM}}`、`{{weekday}}` 等,以及個別日期時間 token,每秒自動更新。
- **顯示自訂**:字型、字級、文字/背景顏色、捲動速度、重複間距,以及置中位置微調。
- **多語系設定面板**:英文、繁體中文、簡體中文、日文、韓文,會跟著 Stream Deck 軟體介面語言自動切換。

## 系統需求

- Stream Deck 軟體 6.6 以上版本
- macOS 10.15+ 或 Windows 10+
- 第一次開啟設定面板時需要網路連線(面板從 CDN 載入 [sdpi-components](https://sdpi-components.dev/) UI 元件庫)

## 安裝方式

雙擊 `.streamDeckPlugin` 檔案即可安裝。如果已經裝過舊版本,這個動作會原地更新——既有的鍵設定(文字、顏色、分組)都會保留,因為這些是存在 Stream Deck 軟體本身,不是包在外掛檔案裡。

## 使用方式

1. 把「跑馬燈片段 (Marquee Segment)」動作放到同一排(橫排方向)或同一欄(直排方向)的每一顆鍵上。
2. 給它們相同的 **Group ID**(單一跑馬燈用預設的 `row1` 就好)。
3. 在其中任何一顆鍵編輯文字、方向、速度或顏色——其他鍵會自動同步。

每顆鍵會依照自己實際所在的欄位置(橫排方向)或列位置(直排方向)自動判斷該顯示哪一段文字,大部分情況下不需要手動設定位置。

### 可用變數

在跑馬燈文字裡使用,每秒都會重新計算。

| Token | 範例輸出 |
| --- | --- |
| `{{date}}` | 2026/07/26 |
| `{{time}}` | 09:05:03 |
| `{{HH:MM}}` | 09:05 |
| `{{HH:MM:SS}}` | 09:05:03 |
| `{{YYYY-MM-DD}}` | 2026-07-26 |
| `{{weekday}}` | 星期日(固定中文輸出,不受設定面板語言影響) |

個別單獨 token `{{YYYY}}` `{{MM}}` `{{DD}}` `{{HH}}` `{{mm}}` `{{ss}}` 可以混在自訂文字裡,例如 `現在 {{HH}}點{{mm}}分`。

### 注意事項

- **直排方向(由上往下/由下往上)** 需要把鍵排成同一「欄」,而不是同一「排」——直排模式是靠每顆鍵的列位置來分辨彼此,如果鍵還是散在同一排,全部都會判斷成同一個位置。
- **字型** 是直接指定名稱,沒有自動 fallback。選到電腦上沒安裝的字型(常見於 Windows 專屬字型如 Impact、Verdana、Comic Sans MS)時,畫面會維持上一個能辨識的字型。
