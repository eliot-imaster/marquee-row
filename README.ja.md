# Marquee Row

<p align="center">
<a href="README.md">English</a> | <a href="README.zh-TW.md">繁體中文</a>
</p>

Stream Deck の一列(または一段)のキーをつなげて、1つの流れるマーキー表示に変えるプラグインです。同じ行のすべてのキーにこのアクションを配置すると、昔ながらの電光掲示板のように、行全体にわたって連続したスクロールテキストが表示されます。

## 主な機能

- **複数キーにまたがる描画**:1つのテキストが、グループに割り当てたすべてのキーをまたいでシームレスにスクロールします。各キーは自分の物理的な列/行位置から、表示すべき部分を自動的に判断します。
- **グループ同期**:同じ Group ID のキーは、テキスト・速度・色・方向をすべて共有します。グループ内のどれか1つのキーを編集すると、他のキーも自動的に同期されます——テキストの入力は1回だけで済みます。
- **4方向のスクロール**:右から左、左から右(横書き)、上から下、下から上(縦書き、文字が1文字ずつ縦に積み重なり、日本語/韓国語/簡体字中国語/繁体字中国語のレイアウトに対応)。
- **リアルタイム変数**:`{{date}}`、`{{time}}`、`{{HH:MM}}`、`{{weekday}}` などの日付・時刻トークンが、毎秒自動的に更新されます。
- **表示のカスタマイズ**:フォント、フォントサイズ、文字色・背景色、スクロール速度、繰り返し間隔、中央揃えの位置微調整。
- **多言語対応の設定パネル**:英語、繁体字中国語、簡体字中国語、日本語、韓国語に対応し、Stream Deck アプリの表示言語に自動で切り替わります。

## 動作環境

- Stream Deck ソフトウェア 6.6 以降
- macOS 10.15 以降、または Windows 10 以降
- 設定パネルを初めて開く際にインターネット接続が必要です(パネルは CDN から [sdpi-components](https://sdpi-components.dev/) UI コンポーネントライブラリを読み込みます)

## インストール方法

`.streamDeckPlugin` ファイルをダブルクリックしてインストールしてください。すでに旧バージョンがインストールされている場合は、その場で上書き更新されます——各キーの設定(テキスト、色、グループ設定)は Stream Deck アプリ自体に保存されており、プラグイン本体には含まれていないため、そのまま引き継がれます。

## 使い方

1. 「マーキーセグメント (Marquee Segment)」アクションを、同じ行(横方向の場合)または同じ列(縦方向の場合)のすべてのキーに配置します。
2. すべてのキーに同じ **Group ID** を設定します(1つのマーキーだけなら、デフォルトの `row1` のままで問題ありません)。
3. グループ内のどれか1つのキーでテキスト・方向・速度・色を編集すると、他のキーも自動的に同期されます。

各キーは、自分の物理的な列位置(横方向)または行位置(縦方向)から、表示すべきテキストの部分を自動的に判断するため、ほとんどの場合は位置を手動で設定する必要はありません。

### 使用可能な変数

マーキーテキスト内で使用でき、毎秒再計算されます。

| トークン | 出力例 |
| --- | --- |
| `{{date}}` | 2026/07/26 |
| `{{time}}` | 09:05:03 |
| `{{HH:MM}}` | 09:05 |
| `{{HH:MM:SS}}` | 09:05:03 |
| `{{YYYY-MM-DD}}` | 2026-07-26 |
| `{{weekday}}` | 星期日(設定パネルの言語に関わらず、常に中国語表記で出力されます) |

個別トークン `{{YYYY}}` `{{MM}}` `{{DD}}` `{{HH}}` `{{mm}}` `{{ss}}` は自由なテキストに混ぜて使用できます。例:`現在 {{HH}}時{{mm}}分`。

### 注意事項

- **縦方向のスクロール(上から下/下から上)** を使う場合、キーは同じ「行」ではなく同じ「列」に配置する必要があります——縦方向モードでは各キーの行位置でメンバーを区別するため、キーが同じ行に並んだままだと、すべて同じ位置として判定されてしまいます。
- **フォント** は名前を直接指定する方式で、自動フォールバックはありません。インストールされていないフォント(Impact、Verdana、Comic Sans MS など Windows 専用フォントに多い)を選ぶと、直前に正しく認識できたフォントのまま表示されます。
